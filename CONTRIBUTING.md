## 🇸🇦 للمساهمين العرب

### قبل أي مساهمة
1. افتح **Issue** أولاً تشرح فيه ما تريد إضافته أو تعديله
2. انتظر الرد قبل البدء في الكود
3. لا تعدّل على Gate System أو Critical Rules بدون نقاش

### طريقة المساهمة (Fork → Edit → PR)
```bash
# 1. Fork الريبو من GitHub

# 2. Clone نسختك
git clone https://github.com/[حسابك]/creative-ui-ux-skill.git

# 3. أنشئ Branch باسم تعديلك
git checkout -b add-[اسم الإضافة]

# 4. عدّل أو أضف ما تريد

# 5. Commit مع رسالة واضحة
git add .
git commit -m "✨ Add: [وصف التعديل بالعربي أو الإنجليزي]"

# 6. Push
git push origin add-[اسم الإضافة]

# 7. افتح Pull Request على الريبو الأصلي
```

### قواعد المساهمة
```
✅ يجب:
  • الإبقاء على: © Mohamed Saleh في أي ملف تعدّله
  • إضافة منصات جديدة في platforms/ فقط
  • إضافة مراجع جديدة في references/ فقط
  • توثيق أي تغيير في Critical Rules
  • كتابة التوثيق بالعربية والإنجليزية معاً إذا كان قسماً جديداً

❌ ممنوع:
  • تعديل Gate System بدون Issue مناقش أولاً
  • إزالة أي Critical Rule
  • إضافة مسارات ثابتة (Hardcoded Paths)
  • إضافة أدوات مدفوعة كمتطلب
  • حذف حقوق المؤلف من أي ملف
```

### أنواع المساهمات المرحّب بها
```
🌐 منصات جديدة:    Webflow, Wix, Flutter Web...
📚 مراجع إضافية:   مكتبات، خطوط، أدوات جديدة
🐛 تصحيح أخطاء:    تصحيح معلومة قديمة أو خاطئة
🌍 ترجمة:          إضافة لغة ثالثة للتوثيق
💡 تحسينات:        توضيح تعليمات غامضة
```

## 🇬🇧 For International Contributors

### Before Any Contribution
1. Open an **Issue** first explaining what you want to add or change
2. Wait for feedback before writing code
3. Do not modify the Gate System or Critical Rules without discussion

### Contribution Workflow (Fork → Edit → PR)
```bash
# 1. Fork the repo on GitHub

# 2. Clone your fork
git clone https://github.com/[your-username]/creative-ui-ux-skill.git

# 3. Create a branch named after your change
git checkout -b add-[feature-name]

# 4. Make your changes

# 5. Commit with a clear message
git add .
git commit -m "✨ Add: [description of change]"

# 6. Push
git push origin add-[feature-name]

# 7. Open a Pull Request on the original repo
```

### Contribution Rules
```
✅ Required:
  • Keep: © Mohamed Saleh in any file you modify
  • New platforms → platforms/ folder only
  • New references → references/ folder only
  • Document Critical Rule changes clearly
  • Write new documentation sections in both Arabic + English

❌ Not Allowed:
  • Modifying the Gate System without a prior open Issue
  • Removing any Critical Rule
  • Adding hardcoded paths
  • Adding paid tools as requirements
  • Removing author credits from any file
```

### Welcome Contributions
```
🌐 New platforms:   Webflow, Wix, Flutter Web...
📚 References:      New libraries, fonts, tools
🐛 Bug fixes:       Outdated or incorrect information
🌍 Translations:    Adding a third language to docs
💡 Improvements:    Clarifying ambiguous instructions
```

## 📝 Commit Message Format

```
✨ Add:    new feature or file
🐛 Fix:    bug or incorrect info
📝 Docs:   documentation only
🔥 Remove: deleted something
♻️ Update: modified existing content

Examples:
  ✨ Add: flutter-web platform guide
  🐛 Fix: shopify liquid section template
  📝 Docs: clarify Gate B checklist
```
