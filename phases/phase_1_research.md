# 🔍 Phase 1 — Research & Inspiration (البحث والإلهام)

> ⚡ هذه المرحلة هي ما يميز هذه المهارة عن أي AI آخر.
> هنا نبحث عن مصادر حقيقية وحديثة — لا ذاكرة محفوظة.

---

## الخطوة 1 — البحث عن مكتبات UI حديثة

```
الـ AI ← يبحث حياً (ليس من الذاكرة):

🔎 استراتيجيات البحث الإجبارية:
  search_web: "best new UI component library [السنة الحالية]"
  search_web: "creative frontend libraries github [نوع المشروع]"
  search_web: "[نوع المشروع] UI kit github stars:>1000"

قواعد فلترة المكتبات:
  ✅ أكثر من 500 نجمة على GitHub
  ✅ آخر تحديث: خلال سنة
  ✅ ليست في القائمة السوداء (core/00_critical_rules.md)
  ✅ حجمها مناسب للمشروع
  ❌ تجاهل أي مكتبة لا تجتاز هذه المعايير
```

## الخطوة 2 — تقديم خيارات المكتبات للعميل

```
الـ AI ← يقدم أفضل 3 مكتبات مع:

| # | المكتبة | النجوم | آخر تحديث | الحجم | لماذا مناسبة؟ |
|---|---|---|---|---|---|
| 1 | [الاسم + رابط GitHub فُتح فعلاً] | ★___K (كما في الصفحة بتاريخ اليوم) | ___ | ___KB (المصدر: bundlephobia/pkg-size أو "لم يُقَس") | ___________ |
| 2 | [الاسم + رابط GitHub] | ★___K | ___ | ___KB | ___________ |
| 3 | [الاسم + رابط GitHub] | ★___K | ___ | ___KB | ___________ |
```

## الخطوة 3 — البحث عن إلهام التصميم

```
الـ AI ← يبحث عن مواقع/تطبيقات فعلية في نفس مجال العميل:

🔎 مصادر الإلهام:
  search_web: "best [مجال المشروع] website design [السنة الحالية]"
  search_web: "awwwards [مجال المشروع]"
  search_web: "[مجال المشروع] app UI design inspiration"
  → إذا أعطى العميل مراجع في Phase 0 ← استخدمها أولاً

الـ AI ← يفتح أفضل 3 مواقع ويقرأها (read_url_content) — وإن لم تتوفر أداة قراءة الروابط: قل ذلك واطلب من العميل لقطات شاشة
الـ AI ← يستخلص منها:
  • نمط الألوان السائد
  • نمط التخطيط
  • أسلوب الأنيميشن
  • نمط الخطوط

الـ AI ← يقدم للعميل:
  "استلهمنا من [الموقع X] أسلوب التخطيط...
   ومن [الموقع Y] طريقة التعامل مع..."
```

---

## الخطوة 4 — قراءة وثائق المكتبة المختارة

```
بعد اختيار العميل للمكتبة:

الـ AI ← يفتح الوثائق الرسمية (read_url_content أو GitHub)
الـ AI ← يستخرج:
  • قائمة المكونات المتاحة
  • طريقة التثبيت (npm install ...)
  • حجم المكتبة الفعلي (Bundle Size)
  • أمثلة الكود الحقيقية
  • نظام الـ Theming إن وجد

⚠️ ممنوع كتابة كود مكون من الذاكرة
   الكود يجب أن يكون مبنياً على ما قُرئ فعلاً الآن
```
