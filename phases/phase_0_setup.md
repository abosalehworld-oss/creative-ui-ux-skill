# 🏗️ Phase 0 — Project Setup (تجهيز المشروع)

---

## الهدف
تجميع كل المعلومات اللازمة قبل البدء في أي تصميم أو كود.
المشروع المُجهَّز جيداً = نصف العمل منجز.

---

## أسئلة التجهيز الكاملة

```
اسأل العميل وسجّل كل الإجابات:

📌 المشروع:
1. اسم المشروع / العلامة التجارية
2. وصف مختصر (جملة واحدة)
3. المجال (متجر عطور، مدونة طبية، SaaS، مطعم...)

📌 المنصة:
4. نوع المشروع:
   □ 🌐 موقع ويب (React / Next.js / HTML)
   □ 📝 WordPress
   □ 🛍️ Shopify
   □ 📱 Mobile (React Native / Flutter)
   □ 💻 Web App / SaaS
   □ 🖥️ Desktop (Electron / Tauri / Flutter Desktop)

📌 الجمهور:
5. الفئة المستهدفة (العمر، الجنس، الاهتمامات)
6. الدولة / اللغة الرئيسية
7. مستوى الخبرة التقنية للمستخدم

📌 الهوية البصرية:
8. هل يوجد لوجو موجود؟ (نعم → شاركه / لا → Mode C أولاً)
9. هل يوجد نظام ألوان موجود؟ (نعم → شاركه)
10. هل يوجد خطوط محددة؟ (نعم → شاركها)

📌 المحتوى:
11. هل المحتوى جاهز أم سيُوضع لاحقاً؟
12. هل هناك صور / أيقونات جاهزة؟

📌 المراجع:
13. مواقع / تطبيقات تعجبك كمرجع بصري (أي مجال)
14. مواقع / تطبيقات لا تحبها ولماذا؟
15. أي ملاحظات أو متطلبات خاصة؟
```

---

## إنشاء "Project Brief"

بعد جمع الإجابات، الـ AI يُنشئ ملخص المشروع:

```
📋 PROJECT BRIEF:

الاسم: ___________
المنصة: ___________
المجال: ___________
الجمهور: [العمر] | [الدولة] | [اللغة]
الهوية: موجودة / تحتاج بناء
المحتوى: جاهز / غير جاهز
المراجع: [أسماء مواقع مع روابط]
ملاحظات: ___________
```

---

## تحديد المسار بعد التجهيز

```
هل الهوية البصرية موجودة؟

نعم:
  → انتقل مباشرة لـ phase_1_research.md
  → ستُدمج الهوية الموجودة في Gate A

لا:
  → أخبر العميل: "سنبدأ ببناء هويتك البصرية أولاً (15-20 دقيقة)"
  → اذهب لـ brand-identity/phase_1_brand_discovery.md
  → بعد اكتمال الهوية → عد لـ phase_1_research.md
```
