# 🚨 القواعد الحرجة (Critical Rules)
> اقرأ هذا الملف قبل أي عمل في أي Mode.

---

## CRITICAL RULE 1 — ممنوع الاعتماد على الذاكرة (ANTI-MEMORY)
لا تستخدم أي مكتبة UI أو نظام ألوان أو خطوط من ذاكرتك مباشرة.
قبل كل مشروع → ابحث حياً في GitHub والويب.
السبب: ذاكرتك = بيانات تدريب قديمة = AI Slop.

---

## CRITICAL RULE 2 — المكتبات المحظورة (BANNED LIBRARIES)
❌ Bootstrap (أي إصدار)
❌ Material UI / MUI بالإعدادات الافتراضية
❌ Ant Design بالإعدادات الافتراضية
❌ TailwindUI Templates بدون تعديل جذري
❌ أي Template جاهز بدون إعادة تصميم كاملة
❌ jQuery (استخدم Vanilla JS)
❌ Moment.js (استخدم Day.js أو date-fns)
❌ Lodash كاملة (استخدم Native JS)

✅ المسموح: مكتبات حديثة مكتشفة بالبحث الحي
✅ Tailwind CSS كأداة utility فقط مع ألوان مخصصة 100%

---

## CRITICAL RULE 3 — ممنوع التخطي (NO SKIPPING)
كل Gate يجب أن يوافق عليه العميل قبل المتابعة.
إذا ذكّرك العميل بخطوة نسيتها → أنت فشلت.

---

## CRITICAL RULE 4 — إعادة القراءة الإجبارية (MANDATORY RE-READ)
إذا تجاوزت المحادثة 15 رسالة:
أعلن: "⚠️ المحادثة طويلة — أعيد قراءة SKILL.md الآن"
ثم أعد قراءة الملفات المطلوبة للـ Mode الحالي.

---

## CRITICAL RULE 5 — التحقق بالدليل (PROOF-BY-QUOTE)
في كل Gate، لا تقل "✅ تم" فقط.
يجب اقتباس دليل من الكود الفعلي:
✅ "المكتبة: magic-ui — تم اكتشافها من GitHub بتاريخ اليوم"
✅ "اللون الأساسي: --primary: #1a1a2e — ليس من Tailwind"
❌ إذا لم تستطع الاقتباس → البند فاشل وأعد العمل.

---

## CRITICAL RULE 6 — يونيفرسال وبدون تبعيات (UNIVERSAL & PORTABLE)
- لا مسارات ثابتة (Hardcoded Paths)
- لا اسكريبتات خارجية مطلوبة
- لا أدوات مدفوعة
- كل البحث بأدوات الـ AI المدمجة: Web Search, URL Reading, GitHub Search

---

## CRITICAL RULE 7 — الأداء أولاً (PERFORMANCE-FIRST)
قبل اعتماد أي مكتبة:
- أي مكتبة > 100KB (Gzipped) تحتاج تبريراً قوياً
- Hover effects: استخدم transform و opacity فقط (لا Reflow)
- ممنوع: top, left, width, height في animations
- يجب دائماً: @media (prefers-reduced-motion: reduce) { animation: none }
- الأولوية: الأداء > الجماليات دائماً

---

## CRITICAL RULE 8 — ثنائي اللغة (BILINGUAL AUTO-DETECT)
هذه المهارة تخدم العرب والعالم معاً — أي شخص في أي دولة.

**كيف يعمل الكشف التلقائي؟**
- اللغة تُكتشف من **نص أول رسالة يكتبها المستخدم** — وليس من دولته أو IP أو إعدادات جهازه.
- **كتب بالعربية؟** → رد بالعربية في كل المحادثة.
- **كتب بالإنجليزية؟** → رد بالإنجليزية في كل المحادثة.
- **كتب بلغة أخرى (فرنسية، إسبانية، تركية...)?** → رد بنفس لغته إذا أمكن، وإلا استخدم الإنجليزية.
- **إذا خلط لغتين** → استخدم اللغة السائدة، أو اسأله مرة واحدة: "Preferred language? / اللغة المفضلة؟"
- **لا تغيّر اللغة** في منتصف المحادثة إلا إذا طلب المستخدم ذلك صراحةً.

**ثوابت بغض النظر عن اللغة:**
- الكود دائماً بالإنجليزية: Class names, Variables, Function names, Comments
- أسماء الملفات دائماً بالإنجليزية
- المحتوى النصي داخل الكود (Labels, Placeholder, Copy) يتبع لغة المشروع نفسه
