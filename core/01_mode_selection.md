# 🔀 اختيار الوضع (Mode Selection)

---

## الخطوة الأولى — اسأل هذا السؤال دائماً

```
"ماذا تحتاج؟

  🎨 Mode C — هوية بصرية ولوجو فقط
  🆕 Mode A — مشروع جديد من الصفر
  🔍 Mode B — تقييم وتحسين مشروع موجود"
```

---

## 🎨 Mode C — هوية بصرية ولوجو

### متى تستخدمه؟
- العميل يحتاج لوجو + نظام ألوان + خطوط فقط
- بدون بناء موقع أو تطبيق في الجلسة الحالية

### أسئلة تجهيز Mode C

```
اسأل العميل:
1. اسم العلامة التجارية / المشروع
2. مجال النشاط (متجر، شركة، شخصي...)
3. الجمهور المستهدف (العمر، الجنس، الدولة)
4. 3 كلمات تصف الشخصية المطلوبة
   مثال: "فاخر، حديث، موثوق"
5. ألوان تحبها / تكرهها
6. لوجوهات أو علامات تجارية تعجبك كمرجع
7. هل تحتاج الشعار بالعربي أم الإنجليزي أم الاثنين؟
```

---

## 🆕 Mode A — مشروع جديد

### متى تستخدمه؟
- بناء موقع أو تطبيق من الصفر
- إعادة تصميم كاملة لمشروع موجود

### أسئلة تجهيز Mode A

```
اسأل العميل:
1. نوع المشروع:
   • 🌐 موقع ويب (برمجة خاصة — React/Next.js/HTML)
   • 📝 موقع WordPress
   • 🛍️ متجر Shopify
   • 📱 موبايل أبلكيشن (React Native / Flutter)
   • 💻 ويب أبلكيشن (SaaS / Dashboard)
   • 🖥️ ديسكتوب أبلكيشن (Electron / Tauri / Flutter Desktop)

2. مجال المشروع (مثال: متجر عطور، مدونة طبية...)

3. الجمهور المستهدف (الفئة العمرية، الدولة، اللغة)

4. هل يوجد هوية بصرية سابقة (لوجو، ألوان)؟
   • نعم → سندمجها في Gate A
   • لا  → سنبدأ بـ Mode C أولاً لبناء الهوية

5. هل لديك مواقع / تطبيقات تعجبك كمرجع؟
```

---

## 🔍 Mode B — تقييم مشروع موجود

### متى تستخدمه؟
- يوجد موقع/تطبيق منشور يريد تقييمه
- شكاوى من البطء أو التصميم القديم

### أسئلة تجهيز Mode B

```
اسأل العميل:
1. رابط الموقع / اسم التطبيق
2. نوع المشروع (WordPress / Shopify / React / Mobile...)
3. الشكاوى الموجودة إن وجدت:
   • "الموقع بطيء"
   • "التصميم قديم"
   • "لا يعمل على الموبايل"
   • "أريد تحسين شامل"
4. هل هناك صفحات معينة تريد التركيز عليها؟
```

---

## ⚠️ قاعدة مهمة
إذا قال العميل "أريد مشروع جديد" بدون هوية بصرية موجودة:
→ ابدأ بـ **Mode C** أولاً لبناء الهوية
→ ثم انتقل تلقائياً لـ **Mode A** مع الهوية الجديدة
→ أخبر العميل بهذا الترتيب صراحةً قبل البدء
