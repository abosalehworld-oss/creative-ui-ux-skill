## الخطوة 3 — توليد اللوجو (SVG Generation)

بعد موافقة العميل على المفهوم:

```
الـ AI ← يكتب كود SVG للوجو:
  • SVG نظيف وقابل للتوسع (scalable)
  • يعمل على خلفيات فاتحة وداكنة
  • بدون تبعيات خارجية
  • يمكن تعديله بسهولة

⚠️ قواعد SVG:
  • استخدم viewBox صحيح
  • لا hardcoded width/height في الـ SVG root
  • الألوان كـ CSS Variables أو currentColor
  • اختبر على خلفية بيضاء وسوداء
```

---

## الخطوة 4 — تنويعات اللوجو (Logo Variations)

بعد اعتماد اللوجو الرئيسي، اصنع:

```
1. Full Logo: رمز + اسم (أفقي)
2. Stacked Logo: رمز + اسم (عمودي)
3. Icon Only: الرمز وحده (للـ Favicon والأيقونات)
4. Wordmark Only: الاسم وحده (لبعض الاستخدامات)
5. Dark Version: للخلفيات الداكنة
6. Light Version: للخلفيات الفاتحة
7. Monochrome: نسخة بلون واحد (للطباعة)
```
