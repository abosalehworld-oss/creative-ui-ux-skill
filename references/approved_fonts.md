## 💡 نصائح اختيار الخطوط

```
Font Pairing Rules:
  ✅ Display Geometric + Body Humanist = متوازن
  ✅ Serif Display + Sans-serif Body = كلاسيك حديث
  ✅ Bold Wide Display + Light Neutral Body = تباين قوي
  ❌ Serif + Serif = ثقيل
  ❌ Geometric + Geometric = ممل

أوزان موصى بها:
  Display Font: 700, 800, 900 فقط
  Body Font: 400 (Regular), 500 (Medium), 600 (SemiBold)

مصادر إضافية للاكتشاف:
  https://fontshare.com/       (مجاني، خطوط احترافية)
  https://fonts.google.com/   (مجاني، موثوق)
  https://typescale.com/      (Type Scale calculator)
  https://fontpair.co/        (Font pairing suggestions)
```
