## 📸 صور فوتوغرافية مجانية (Free Stock Photos)

| المصدر | الرخصة | الأفضل لـ | الرابط |
|---|---|---|---|
| **Unsplash** | مجاني للاستخدام التجاري | كل شيء — أكبر مكتبة | unsplash.com |
| **Pexels** | مجاني للاستخدام التجاري | صور وفيديوهات | pexels.com |
| **Pixabay** | مجاني | صور + vectors + فيديو | pixabay.com |
| **Burst (Shopify)** | مجاني | E-commerce تحديداً | burst.shopify.com |
| **Rawpixel** | مجاني + مدفوع | PSD + PNG + Mockups | rawpixel.com |

```
⚠️ قاعدة مهمة:
  • لا تستخدم صور Stock وأنت تقدر تطلب من العميل صوره الحقيقية
  • صور Stock = أحسن من "لا صور"، لكن أسوأ من صور حقيقية
  • اختر صور تتناسب مع Palette الألوان المعتمدة في Gate A
```

## 🎨 أيقونات (Icons)

| المصدر | النوع | العدد | الأفضل لـ |
|---|---|---|---|
| **Lucide** | SVG Stroke | 1500+ | الأفضل عموماً — خفيفة ونظيفة |
| **Heroicons** | SVG Stroke + Solid | 300+ | Tailwind projects |
| **Phosphor** | SVG متعددة الأوزان | 7000+ | التنوع الأكبر |
| **Tabler Icons** | SVG Stroke | 5000+ | Dashboard / Admin |
| **Radix Icons** | SVG Minimal | 300+ | Shadcn projects |
| **Feather Icons** | SVG Stroke | 280+ | بسيطة وكلاسيكية |

```
⚠️ قاعدة الأداء:
  • استخدم SVG inline أو sprite — لا تحمّل مكتبة أيقونات كاملة

  • الأفضل: انسخ SVG مباشرة في الكود
```

  الـ AI ← يُرفق قائمة بكل الأصول المستخدمة مع مصادرها
