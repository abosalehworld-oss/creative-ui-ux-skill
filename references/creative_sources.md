## ⚠️ How the AI Uses This File / كيف يستخدم الـ AI هذا الملف

```
1. Logo project (Mode C):
   → Search Logo sources → Color sources → Typography sources
   → Must cite at least 3 sources in the research summary

2. New project (Mode A):
   → Search UI sources (matching platform) → Color → Typography → Logo (if needed)
   → Must cite at least 3 sources in the research summary

3. Audit (Mode B):
   → Compare existing design against top examples from UI sources
   → Reference what "good" looks like in the audit report

Rule: The AI must write a research summary BEFORE designing.
      "I searched [X] sources and found: ..."
      No summary = No designing.

القاعدة: الـ AI يكتب ملخص بحث قبل أي تصميم.
         "بحثت في [X] مصادر ووجدت: ..."
         بدون ملخص = بدون تصميم.
```
